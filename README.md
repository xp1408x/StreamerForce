# 🎮 Streamforce: Ecosistema Multi-Juego

Este es un proyecto integral (Fullstack) diseñado para comunidades de gaming y streamers. Combina la potencia de **Next.js 15+** en el frontend con una arquitectura de **Supabase (PostgreSQL)** altamente auditada.

## 🚀 Características principales
- **Gestión de Identidades:** Vinculación de cuentas de Minecraft, Steam, etc.
- **Economía Virtual:** Sistema de Wallets y Tienda integrada con Stripe.
- **Seguridad Avanzada:** Roles jerárquicos y auditoría total de cambios.
- **Gestión de Streams:** Calendarios y slots para creadores de contenido.

## 📂 Estructura del Proyecto
- `app/`: Aplicación Next.js (Frontend y API Routes).
- `scripts/`: Esquemas SQL, Triggers y Funciones de la base de datos.
- `public/`: Activos estáticos.
- `requierements.md`: Documento de requisitos técnicos y especificaciones del proyecto.

## 🛠️ Instalación y Desarrollo

1. Clona el repositorio.
2. Instala las dependencias: `npm install`.
3. Configura tus variables de entorno en un archivo `.env.local`.
4. Ejecuta el entorno de desarrollo: `npm run dev`.
5. Los scripts de la base de datos para Supabase se encuentran en la carpeta `scripts`.
